# คู่มือผู้ดูแลระบบ (Admin Guide)

ผู้ดูแลระบบมีหน้าที่ดูแลภาพรวมของนักศึกษาฝึกงานทั้งหมดในองค์กร

## 1. Dashboard สรุปผลภาพรวม

หน้า Dashboard ของ Admin จะแสดงตัวเลขสถิติที่สำคัญ:
- **จำนวนนักศึกษาทั้งหมด:** ที่กำลังฝึกงานอยู่ในปัจจุบัน
- **อัตราการลา/สาย/ขาด:** คำนวณเป็นเปอร์เซ็นต์เทียบกับจำนวนนักศึกษาทั้งหมด
- **หน่วยงานที่มีสถิติสูงสุด:** กราฟแสดง 5 อันดับหน่วยงานที่มีอัตราการลาหรือสายสูงสุด เพื่อการวิเคราะห์และปรับปรุง

![Admin Dashboard](/img/frontend-itt/admin_dashboard.png)

## 2. การตรวจสอบรายชื่อนักศึกษา

Admin สามารถค้นหานักศึกษาได้จาก:
- ชื่อ-นามสกุล
- ตำแหน่ง
- หน่วยงาน/สังกัด
- มหาวิทยาลัย

สามารถคลิกที่รายชื่อเพื่อดูรายละเอียดประวัติการลงเวลาและสถิติรายบุคคลอย่างละเอียด

## 3. การส่งออกข้อมูล (Export Data)

Admin สามารถส่งออกข้อมูลการลงเวลาของนักศึกษาออกมาเป็นไฟล์ **CSV** เพื่อนำไปใช้งานในโปรแกรม Microsoft Excel หรือระบบอื่นๆ ของ กฟภ. ได้โดยการกดปุ่ม **"ส่งออกตาราง"**
