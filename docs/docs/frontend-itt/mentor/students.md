# นักศึกษาในความดูแล (My Students)


หน้านี้ใช้สำหรับ **พี่เลี้ยง (Mentor)** เพื่อติดตามสถานะและสถิติการปฏิบัติงานของนักศึกษาทุกคนที่อยู่ในความรับผิดชอบ

## รายชื่อนักศึกษา

พี่เลี้ยงสามารถดูรายชื่อนักศึกษาในกลุ่มได้ทั้งหมด โดยระบบจะแสดงข้อมูลเบื้องต้นดังนี้:
- **ชื่อ-นามสกุล:** ข้อมูลพื้นฐานของนักศึกษา
- **สถานะปัจจุบัน:** แสดงว่านักศึกษากำลัง "ปฏิบัติงาน", "ออกงาน", "ลา" หรือ "ทำงานนอกสถานที่"
- **อัตราการมาเรียน (Attendance Rate):** สถิติร้อยละของการมาปฏิบัติงานจริงเทียบกับวันทำการทั้งหมด
- **สถานะผลพิจารณา:** การแสดงผลสถานะการฝึกงาน(อยู่ระหว่างฝึกงาน, รออนุมัติการฝึกงาน, ชดเชยวันทำงาน, ผ่านการฝึกงาน )

![Mentor Students](/img/frontend-itt/studentmentor.png)
*หน้าจอแสดงรายชื่อนักศึกษาและสถานะปัจจุบัน*

## รายละเอียดรายบุคคล

เมื่อคลิกที่ชื่อนักศึกษา พี่เลี้ยงจะสามารถเข้าถึงข้อมูลเชิงลึกได้:
1. **ประวัตินักศึกษา:** ข้อมูลนักศึกษา
2. **ประวัติการลงเวลา:** ตรวจสอบย้อนหลังได้ทุกวัน
3. **ประวัติการลา:** สรุปจำนวนวันลาแยกตามประเภท (ลากิจ, ลาป่วย) แสดงเหตุการลาและรูปหลักฐาน
4. **ชั่วโมงการทำงาน:** ตรวจสอบชั่วโมงการทำงานของนักศึกษา
5. **สถานะผลพิจารณา:** การแสดงผลสถานะการฝึกงาน(อยู่ระหว่างฝึกงาน, รออนุมัติการฝึกงาน, ชดเชยวันทำงาน, ผ่านการฝึกงาน )
