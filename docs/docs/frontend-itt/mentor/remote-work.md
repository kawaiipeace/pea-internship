# 🌍 งานนอกสถานที่ (Offsite Work)

ระบบ **Remote Work** ออกแบบมาเพื่อเพิ่มความคล่องตัวในการปฏิบัติงาน ช่วยให้นักศึกษาสามารถลงเวลาเข้า-ออกงานได้จากสถานที่อื่นๆ นอกเหนือจากสำนักงานหลัก โดยยังคงความถูกต้องของข้อมูลผ่านการอนุมัติจากพี่เลี้ยง

![Mentor Remote Work Overview](/img/frontend-itt/mentor_remote_work.png)
*แดชบอร์ดจัดการงานนอกสถานที่สำหรับพี่เลี้ยง*

---

## 📝 ขั้นตอนการมอบหมายงาน

พี่เลี้ยงสามารถมอบหมายงานให้นักศึกษาได้ง่ายๆ ผ่านเมนู **"งานนอกสถานที่"** ตามขั้นตอนดังนี้:

1. **เลือกสถานที่:** ระบุชื่อสถานที่หรือหน่วยงานที่นักศึกษาไปปฏิบัติงาน
2. **กำหนดช่วงเวลา:** เลือกวันที่เริ่มต้นและสิ้นสุดการปฏิบัติงาน
3. **เลือกนักศึกษา:** เลือกรายชื่อนักศึกษาที่ต้องการมอบหมาย (สามารถเลือกได้หลายคนพร้อมกัน)
4. **บันทึกข้อมูล:** เมื่อกดยืนยัน ระบบจะเปิดสิทธิ์การลงเวลาตามพิกัดของสถานที่นั้นๆ ทันที

![Remote Work Form](/img/frontend-itt/remote_work_form.png)
*หน้าจอแบบฟอร์มการมอบหมายงานนอกสถานที่*

---

## 💡 สิ่งที่จะเกิดขึ้นเมื่อมีการมอบหมาย

เมื่อพี่เลี้ยงทำการมอบหมายงานสำเร็จ ระบบจะดำเนินการดังนี้:

- **สถานะพิเศษ:** ในหน้า Dashboard ของนักศึกษาจะแสดงสถานะเป็น **"นอกสถานที่"**
- **ปลดล็อค GPS:** นักศึกษาสามารถกดลงเวลาได้โดยระบบจะตรวจสอบพิกัดอ้างอิงจากสถานที่ที่ได้รับมอบหมายแทนสำนักงานหลัก
- **บันทึกอัตโนมัติ:** ชื่อสถานที่ปฏิบัติงานจะถูกบันทึกลงใน Report การลงเวลาโดยอัตโนมัติ

![Remote Work Details](/img/frontend-itt/remote_work1.png)
*การแสดงผลรายการงานนอกสถานที่ที่สร้างไว้*

![Student Details](/img/frontend-itt/remote_work_id.png)
*พี่เลี้ยงสามารถกดดูรายละเอียดการลงเวลาของนักศึกษาแต่ละคนในทริปนั้นๆ ได้*

---

## ⚠️ เงื่อนไขและการแก้ไขข้อมูล

> [!IMPORTANT]
> **กฎการแก้ไขและลบข้อมูล:**
> - พี่เลี้ยงสามารถแก้ไขหรือลบข้อมูลการมอบหมายได้ **ก่อนที่จะถึงวันที่กำหนด** เท่านั้น
> - หากผ่านวันที่ปฏิบัติงานมาแล้ว หรืออยู่ในช่วงวันที่กำลังปฏิบัติงาน **จะไม่สามารถแก้ไขหรือลบข้อมูลได้** เพื่อป้องกันความสับสนของข้อมูลการลงเวลา

> [!TIP]
> การลงเวลานอกสถานที่จะเปิดให้ใช้งานได้เฉพาะ **ในวันที่พี่เลี้ยงกำหนดไว้เท่านั้น** หากไม่มีการมอบหมายหรืออยู่นอกเหนือช่วงเวลา นักศึกษาจำเป็นต้องกลับมาลงเวลาที่สำนักงานหลักตามปกติ
