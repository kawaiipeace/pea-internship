# งานนอกสถานที่ (Offsite Work)

ระบบรองรับการทำงานนอกสถานที่ (Remote Work) เพื่อให้นักศึกษาสามารถลงเวลาได้แม้ไม่ได้อยู่ในสำนักงานใหญ่

![Intern Dashboard](/img/frontend-itt/mentor_remote_work.png)
*หน้าจอหลักสำหรับพี่เลี้ยงมอบหมายนักศึกษาปฏิบัติงานนอกสถานที่*

## สำหรับพี่เลี้ยง (Mentor)

พี่เลี้ยงสามารถมอบหมายงานนอกสถานที่ให้นักศึกษาได้ผ่านเมนู **"งานนอกสถานที่"**
- ระบุชื่อสถานที่ปฏิบัติงาน
- ระบุวันที่เริ่มต้นและสิ้นสุด
- เมื่อมอบหมายแล้ว นักศึกษาจะสามารถลงเวลาในสถานที่นั้นๆ ได้โดยไม่ติดปัญหา GPS

![Intern Dashboard](/img/frontend-itt/remote_work_form.png)
*หน้าจอหลักสำหรับพี่เลี้ยงใช้ในการกรอกฟอร์มเพื่อมอบหมายนักศึกษาปฏิบัติงานนอกสถานที่*



เมื่อมีการมอบหมายงานนอกสถานที่:
1. ระบบจะแสดงสถานะในหน้าการ์ดว่าวันนี้เป็นการทำงาน **"นอกสถานที่"**
2. นักศึกษาสามารถกดลงเวลาเข้า-ออกงานได้ตามปกติ
3. ระบบจะบันทึกชื่อสถานที่นั้นลงในประวัติการลงเวลาโดยอัตโนมัติ
4. พี่เลี้ยงสามารถกดแก้ไขข้อมูลการมอบหมายงานปฏิบัตินอกสถานที่ได้          แต่เมื่อผ่านวันที่มอบหมายแล้วไม่สามารถกดแก้ไขและกดลบข้อมูลได้

![Intern Dashboard](/img/frontend-itt/remote_work1.png)
*หน้าจอหลักสำหรับพี่เลี้ยงใช้ในการดูรายเอียดการสร้างปฏิบัตงานนอกสถานที่*

![Intern Dashboard](/img/frontend-itt/remote_work_id.png)
*หน้าจอหลักสำหรับพี่เลี้ยงใช้ในการดูรายเอียดการสร้างปฏิบัตงานนอกสถานที่สามารถกดดูรายละเอียดของนักศึกษาแต่ละคนได้*

---

### ข้อควรระวัง
การลงเวลานอกสถานที่จะเปิดให้ใช้งานได้เฉพาะ **ในวันที่พี่เลี้ยงกำหนดไว้เท่านั้น** หากไม่มีการมอบหมาย นักศึกษาต้องกลับมาลงเวลาที่สำนักงานใหญ่ตามปกติ
