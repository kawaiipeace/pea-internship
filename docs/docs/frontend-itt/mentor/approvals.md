# การอนุมัติคำขอ (Approvals)

ฟีเจอร์นี้สำหรับ **พี่เลี้ยง (Mentor)** เพื่อใช้จัดการคำขอต่างๆ จากนักศึกษาในกลุ่มที่ดูแล

## หน้าจอการอนุมัติ

พี่เลี้ยงสามารถเข้าดูคำขอทั้งหมดได้จากเมนูการอนุมัติ ซึ่งจะแบ่งออกเป็น 2 ส่วนหลัก:

1. **คำขอลา (Leave Requests):** แสดงรายการที่นักศึกษาส่งมา
2. **คำขอแก้ไขเวลา (Time Corrections):** แสดงรายการขอปรับปรุงเวลาเข้า-ออกงาน

![Mentor Approval](/img/frontend-itt/mentor_approval.png)
*หน้าจอรายการคำขอที่รอการอนุมัติ*

## ขั้นตอนการพิจารณา

### การอนุมัติ (Approve)
- ตรวจสอบความถูกต้องของวันที่และเหตุผล
- ตรวจสอบไฟล์แนบ (ถ้ามี)
- กดปุ่ม **"อนุมัติ"** เพื่อยืนยันรายการ

### การไม่อนุมัติ (Reject)
- หากข้อมูลไม่ครบถ้วนหรือเหตุผลไม่เพียงพอ ให้กดปุ่ม **"ไม่อนุมัติ"**
- **ระบบจะบังคับให้ระบุเหตุผลที่ไม่อนุมัติ** เพื่อให้นักศึกษาได้รับทราบและดำเนินการแก้ไขต่อไป

---

> [!TIP]
> พี่เลี้ยงควรหมั่นตรวจสอบหน้านี้เป็นประจำ เพื่อไม่ให้คำขอของนักศึกษาค้างอยู่ในระบบนานเกินไป
