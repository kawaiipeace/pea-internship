# 🔐 การเข้าสู่ระบบ (Authentication)

ก่อนเริ่มใช้งานระบบ **PEA Internship Management System (ITT)** ผู้ใช้งานจำเป็นต้องมีบัญชีที่ลงทะเบียนในระบบหลักของ กฟภ. ให้เสร็จสมบูรณ์ และมีสถานะเป็น **"รอฝึกงาน"** หรือ **"กำลังฝึกงาน"** จึงจะสามารถเข้าใช้งานระบบ ITT ได้

---

## 🚀 ช่องทางการเข้าสู่ระบบ

ระบบแบ่งช่องทางการเข้าสู่ระบบตามบทบาทของผู้ใช้งาน เพื่อความสะดวกและความปลอดภัย

### 👨‍🎓 สำหรับนักศึกษา (Student)
นักศึกษาสามารถเข้าสู่ระบบได้ผ่านหน้า Login หลัก โดยระบุอีเมลและรหัสผ่านที่ใช้ในระบบ Internship

![Student Login](/img/frontend-itt/Student_login.png)
*หน้าจอเข้าสู่ระบบสำหรับนักศึกษา*

### 👔 สำหรับพี่เลี้ยงและผู้ดูแลระบบ (Mentor & Admin)
พี่เลี้ยงและผู้ดูแลระบบใช้ช่องทาง Login เฉพาะเพื่อเข้าถึงส่วนการจัดการและพิจารณาคำขอต่างๆ

![Mentor & Admin Login](/img/frontend-itt/mentor_admin.png)
*หน้าจอเข้าสู่ระบบสำหรับพี่เลี้ยงและผู้ดูแลระบบ*

---

## ✨ การตั้งค่าโปรไฟล์ครั้งแรก (First-time Login)

เมื่อนักศึกษาเข้าสู่ระบบเป็นครั้งแรก ระบบจะกำหนดให้คุณ **"ตั้งค่าโปรไฟล์"** เพื่อความสมบูรณ์ของข้อมูลในระบบ

1. **อัปโหลดรูปภาพ:** เพื่อใช้ในการยืนยันตัวตนบน Dashboard
2. **ตั้งชื่อเล่น:** ชื่อที่จะปรากฏในระบบเพื่อให้พี่เลี้ยงจดจำได้ง่าย
3. **ตรวจสอบข้อมูล:** ตรวจสอบความถูกต้องของข้อมูลพื้นฐานก่อนเริ่มใช้งาน

![Add Profile](/img/frontend-itt/Add_Profile.png)
*หน้าจอสำหรับตั้งค่ารูปภาพและชื่อเล่นเมื่อเข้าใช้งานครั้งแรก*

---

## 🛡️ นโยบายความปลอดภัย

> [!CAUTION]
> **เพื่อความปลอดภัยของข้อมูล:**
> - **ห้ามแบ่งปันบัญชี:** บัญชีผู้ใช้งานเป็นสิทธิ์ส่วนบุคคล ห้ามเปิดเผยรหัสผ่านให้ผู้อื่นทราบ
> - **การออกจากระบบ:** ควรคลิก **Logout** ทุกครั้งหลังเลิกใช้งาน โดยเฉพาะเมื่อใช้งานผ่านเครื่องคอมพิวเตอร์สาธารณะ หรืออุปกรณ์ที่ใช้ร่วมกับผู้อื่น
> - **การตรวจสอบสิทธิ์:** ระบบมีการบันทึกประวัติการเข้าใช้งานเพื่อความโปร่งใส

---

> [!TIP]
> หากคุณพบปัญหา "ไม่สามารถเข้าสู่ระบบได้" ทั้งที่มีสถานะรอฝึกงานแล้ว กรุณาตรวจสอบการสะกดอีเมล หรือติดต่อฝ่ายบุคคล (HR) เพื่อตรวจสอบสถานะในระบบหลักอีกครั้ง
