# ภาพรวมระบบ Frontend-ITT

ระบบ **PEA Internship Management System (ITT)** เป็นแพลตฟอร์มที่ออกแบบมาเพื่อจัดการและติดตามการฝึกงานของนักศึกษาใน กฟภ. โดยครอบคลุมตั้งแต่การลงเวลาเข้า-ออกงาน การลา และการจัดการงานนอกสถานที่

## บทบาทผู้ใช้งาน (User Roles)

ระบบแบ่งผู้ใช้งานออกเป็น 3 กลุ่มหลัก ดังนี้:

### 1. นักศึกษา (Intern)
- **ลงเวลาเข้า-ออกงาน:** บันทึกเวลาปฏิบัติงานในแต่ละวันพร้อมการตรวจสอบตำแหน่ง GPS
- **ติดตามความคืบหน้า:** ดูจำนวนชั่วโมงสะสมและสถิติการมาฝึกงาน
- **ส่งคำขอ:** แจ้งลาป่วย/ลากิจ หรือขอแก้ไขเวลาในกรณีที่เกิดข้อผิดพลาด

### 2. พี่เลี้ยง (Mentor)
- **ตรวจสอบคำขอ:** พิจารณาอนุมัติหรือไม่อนุมัติการลาและคำขอแก้ไขเวลาของนักศึกษาในดูแล
- **จัดการงานนอกสถานที่:** มอบหมายและตรวจสอบสถานะการทำงานนอกสถานที่
- **ติดตามนักศึกษา:** ดูสถิติและสถานะปัจจุบันของนักศึกษาทุกคนในกลุ่ม

### 3. ผู้ดูแลระบบ (Admin)
- **Dashboard สรุปผล:** ดูภาพรวมสถิติการฝึกงานทั้งองค์กร (อัตราการลา, สาย, ขาด)
- **จัดการข้อมูล:** ตรวจสอบรายชื่อนักศึกษาและพี่เลี้ยงทั้งหมด
- **ส่งออกข้อมูล:** Export รายงานสรุปผลการฝึกงานเป็นไฟล์ CSV

## การเข้าใช้งานระบบ
- รองรับการใช้งานผ่าน Web Browser ทั้งบน Desktop และ Mobile (PWA)
- มีระบบตรวจสอบตำแหน่ง (Geolocation) เพื่อความถูกต้องในการลงเวลา
