# 🎓 คู่มือการใช้งานสำหรับนักศึกษา (Intern)

ยินดีต้อนรับสู่ระบบ **PEA Internship Management System (ITT)** หน้านี้จะช่วยแนะนำฟีเจอร์สำคัญที่คุณต้องใช้งานในแต่ละวัน เพื่อให้การฝึกงานของคุณเป็นไปอย่างราบรื่นและมีประสิทธิภาพ

---

## 🕒 1. การลงเวลาเข้า-ออกงาน (Check-in/out)

หัวใจสำคัญของการฝึกงานคือการบันทึกเวลาปฏิบัติงาน ระบบจะใช้ตำแหน่ง **GPS** เพื่อยืนยันว่าคุณปฏิบัติงานอยู่ในพื้นที่ที่กำหนด

### ขั้นตอนการลงเวลา:
1.  **เข้างาน (Check-in):** เมื่อถึงที่ทำงาน ให้กดปุ่ม **"ลงเวลาเข้างาน"** บน Dashboard
2.  **ตรวจสอบตำแหน่ง:** ระบบจะยืนยันพิกัด หากคุณอยู่นอกพื้นที่ ระบบจะแจ้งเตือนให้ทราบ
3.  **เลิกงาน (Check-out):** เมื่อถึงเวลาเลิกงาน ให้กดปุ่ม **"ลงเวลาออกงาน"** เพื่อบันทึกชั่วโมงการทำงาน

![Check-in Dashboard](/img/frontend-itt/Check_in.png)
*หน้าจอหลักสำหรับการลงเวลาเข้า-ออกงาน*

> [!TIP]
> **กฎการลงเวลา:**
> - **การสาย:** หากลงเวลาหลัง **08:45 น.** ระบบจะบันทึกสถานะว่า "สาย"
> - **การออกงาน:** คุณสามารถลงเวลาออกได้ตั้งแต่เวลา **16:30 น.** เป็นต้นไป

## 📊 2. ติดตามความคืบหน้าการฝึกงาน

คุณสามารถดูความคืบหน้าของการฝึกงานได้แบบ Real-time ผ่าน **Progress Bar** ในหน้า Dashboard ซึ่งจะแสดง:
- **ชั่วโมงสะสม:** จำนวนชั่วโมงทั้งหมดที่บันทึกสำเร็จ
- **เป้าหมาย:** จำนวนชั่วโมงรวมที่ต้องฝึกงานตามหลักสูตร

![Progress Tracking](/img/frontend-itt/Hour.png)
*แถบแสดงความคืบหน้าของชั่วโมงการฝึกงาน*

---

## 📝 3. การแจ้งลา (Leave Request)

หากมีความจำเป็นต้องลาป่วยหรือลากิจ คุณสามารถส่งคำขอผ่านระบบเพื่อให้พี่เลี้ยงพิจารณาอนุมัติ

### วิธีการส่งคำขอลา:
1. เข้าไปที่เมนู **"การลา"**
2. เลือกประเภทการลา (ลาป่วย / ลากิจ)
3. ระบุวันที่ และเหตุผลความจำเป็น
4. **แนบหลักฐาน:** หากเป็นลาป่วย ควรแนบใบรับรองแพทย์เพื่อความรวดเร็วในการอนุมัติ

![Leave Request Form](/img/frontend-itt/leave-form.png)
*แบบฟอร์มการส่งคำขอลา*

---

## 🛠️ 4. การขอแก้ไขเวลา (Time Correction)

ในกรณีที่เกิดข้อผิดพลาด เช่น ลืมลงเวลา หรือระบบขัดข้อง คุณสามารถส่งคำขอแก้ไขเวลาได้

> [!IMPORTANT]
> คุณสามารถส่งคำขอแก้ไขได้ใน 3 กรณีเท่านั้น: **ไม่ลงเวลาออก**, **ขาด**, และ **สาย**

![Time Correction](/img/frontend-itt/edit-time.png)
*หน้าจอส่งคำขอแก้ไขเวลาปฏิบัติงาน*

---

## 📅 5. ตรวจสอบประวัติ (History)

ระบบจัดเก็บประวัติย่อยเพื่อให้คุณตรวจสอบความถูกต้องของข้อมูลได้ตลอดเวลา

### ประวัติการลงเวลา
แสดงรายละเอียดการเข้า-ออกงานย้อนหลัง พร้อมสรุปจำนวนวันที่เข้างานปกติ, สาย, ลา และขาด ในแต่ละเดือน
![Time History](/img/frontend-itt/checktime_history.png)

### ประวัติการลา
สรุปจำนวนวันลาทั้งหมดที่คุณใช้ไป โดยแยกตามประเภทการลา พร้อมปฏิทินแสดงวันที่ลาชัดเจน
![Leave History](/img/frontend-itt/leave-history.png)
