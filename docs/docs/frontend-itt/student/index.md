# คู่มือสำหรับนักศึกษา (Intern Guide)

หน้านี้อธิบายฟีเจอร์หลักที่นักศึกษาต้องใช้งานในแต่ละวัน

## 1. การลงเวลาเข้า-ออกงาน (Check-in/out)

นักศึกษาสามารถลงเวลาได้ผ่านหน้า Dashboard โดยระบบจะตรวจสอบตำแหน่ง GPS ของคุณ

- **เงื่อนไขการลงเวลา:** ต้องอยู่ในรัศมีที่กำหนดรอบสำนักงานใหญ่ กฟภ. (ยกเว้นกรณีที่มีงานนอกสถานที่)
- **เวลาลงเวลาออก:** สามารถลงเวลาออกได้ตั้งแต่เวลา **16:30 น.** เป็นต้นไป

![Intern Dashboard](/img/frontend-itt/Check_in.png)
*หน้าจอหลักสำหรับการลงเวลาเข้า-ออกงาน*

### ขั้นตอนการใช้งาน:
1. กดปุ่ม **"ลงเวลาเข้างาน"** เมื่อถึงที่ทำงาน
2. ระบบจะแสดงข้อความยืนยันหากตำแหน่งถูกต้อง
3. เมื่อเลิกงาน ให้กดปุ่ม **"ลงเวลาออกงาน"**

-*กรณีกดลงเวลา:* หน้าจอแสดงเมื่อกดเวลาเข้างานถ้าเกินเวลา8.45น.

![Intern Dashboard](/img/frontend-itt/modal_check_in.png)

-*กรณีกดลงเวลาออก:* หน้าจอแสดงเมื่อกดเวลาออกงานได้ตั้งแต่เวลา16.30น.

![Intern Dashboard](/img/frontend-itt/modal_check_out.png)

## 2. ความคืบหน้าการฝึกงาน

ในหน้าหลักจะแสดงแถบความคืบหน้า (Progress Bar) ซึ่งคำนวณจาก:
- **ชั่วโมงสะสม:** จำนวนชั่วโมงที่ทำงานจริง
- **เป้าหมาย:** จำนวนชั่วโมงทั้งหมดที่ต้องฝึกงานตามหลักสูตร

## 3. การแจ้งลา (Leave Request)

หากต้องการลาป่วยหรือลากิจ สามารถทำได้ดังนี้:
1. ไปที่เมนูการลา
2. ระบุประเภทการลา (ลาป่วย/ลากิจ)
3. ระบุวันที่และเหตุผล พร้อมแนบหลักฐาน (ถ้ามี เช่น ใบรับรองแพทย์)
4. รอพี่เลี้ยงอนุมัติในระบบ

## 4. การขอแก้ไขเวลา (Time Correction)

ในกรณีที่ลืมลงเวลาหรือระบบขัดข้อง นักศึกษาสามารถส่งคำขอแก้ไขย้อนหลังได้ โดยต้องระบุเวลาที่ถูกต้องและเหตุผลประกอบเพื่อให้พี่เลี้ยงพิจารณา

## 5. ประวัติการลงเวลา (History)

หากต้องการดูประวัติการลงเวลา สามารถทำได้ดังนี้:
1. ไปที่เมนูประวัติการลงเวลา
2. จะเห็นการ์ดสุปผลว่าแต่ละวันเราใช้ไปทั้งหมดกี่วันแล้ว โดยจะมีรายละเอียด เข้างานปกติ สาย ลา และขาด
3. สามารถเลือกปฏิทินเพื่อดูข้อมูลการลงเวลาของแต่ละเดือนได้

## 6. ประวัติการลา (Leave-History)

หากต้องการดูประวัติการลา สามารถทำได้ดังนี้:
1. ไปที่เมนูประวัติการลา
2. จะเห็นการ์ดสุปผลว่าแต่ละวันเราใช้ไปทั้งหมดกี่วันแล้ว โดยจะมีรายละเอียด ลาทั้งหมด ลาป่วย ลากิจ
3. สามารถเลือกปฏิทินเพื่อดูข้อมูลการลาของแต่ละเดือนได้
